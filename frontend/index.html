Architecture & Supabase Integration

Analyzer.ai follows a clean separated architecture: Frontend → FastAPI → Supabase PostgreSQL → AI Model.

Current State: Ready To Use Out Of The Box!

The backend is running with an automatic local storage engine that completely mirrors the Supabase PostgreSQL schema. You can upload resumes, analyze JDs, view history, and test the admin dashboard immediately!

Connecting Your Supabase PostgreSQL Database

  1. Create a project at supabase.com.
  2. Open the Supabase SQL Editor and run the script located at:
    backend/database/schema.sql
  3. In backend/.env, add your Supabase credentials: 
    SUPABASE_URL=https://your-id.supabase.co
SUPABASE_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
  4. Restart the FastAPI backend. It will automatically detect Supabase and transition from local storage to live PostgreSQL tables with RLS!

AI Provider Integration (Optional)

By default, Analyzer.ai includes an intelligent heuristic AI engine that generates STAR bullet rewrites and interview questions without requiring paid API keys. To connect Google Gemini or OpenAI: 

AI_PROVIDER=gemini  # or openai
AI_API_KEY=your_gemini_api_key_here
AI_MODEL_NAME=gemini-1.5-flash
